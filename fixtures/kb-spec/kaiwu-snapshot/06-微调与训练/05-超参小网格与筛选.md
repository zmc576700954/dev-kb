# 超参小网格与筛选

> 在 0.5B 上做 6 组 2-epoch 短跑，只看 valid loss 与 dev120 全字段准确率，筛出 r=32、lr=2e-4 作为正式训练配置。**这是筛选用短跑，不代表最终效果。**

## 协议

| 项 | 值 |
|---|---|
| 数据 | v5：train 302 / valid 40 / dev120 120 |
| 固定项 | max_len 1536、dropout 0.05、grad_accum 8、warmup 0.05、weight_decay 0.01、packing off、seed 0 |
| 变量 | r ∈ {8, 16, 32}；lr ∈ {1e-4, 2e-4}；alpha 固定为 2r |
| 训练 | 每组 2 epoch（76 optimizer steps），无早停触发 |
| 评测 | dev120，v4 prompt + outlines + 后处理，与基线同口径 |

## 结论

- **最好两组**：r=32/lr=2e-4（valid 0.1039、全字段 0.650）与 r=32/lr=1e-4（valid 0.1269、全字段 0.650、结构字段 0.742 最高）。
- 入选正式训练：**r=32、alpha=64、lr=2e-4、dropout 0.05、max_len 1536、grad_accum 8**。理由：valid loss 最低，全字段与另一组并列最高，urgency 字段最高（0.967）。
- 正式训练 3 seed 的结果：dev120 全字段 0.633–0.675（基线 0.267），Δ +0.367～+0.408，配对 p<0.001；早停落在 ep2/2/4，train loss 降到 0.02 以下后 valid 回升。详见 `evals/tuning-report.md`。
- r=8 明显欠拟合（两组都低于 r=16/32）；lr 从 1e-4 提到 2e-4 在每个 r 上都降 valid loss，说明本轮学习率偏低而非偏高。
- 2 epoch 下 train loss 已到 0.043（r=32/2e-4），继续训练大概率过拟合，因此正式训练必须带早停，不能直接跑满 8 epoch。

## 为什么不能拿这张表当最终结论

- 只有 2 epoch，模型还没收敛到稳定平台；表中差距可能被后续 epoch 反转。
- valid 只有 40 条，0.01 量级的 valid loss 差异不足以区分配置。
- dev120 被用于失败模式定位与改写，短跑在 dev120 上的绝对水平偏乐观；正式结论以 3 seed 的配对检验为准。
- alpha 随 r 同步放大（2r），因此 r 的比较里混有 alpha 变化，不能单独归因于秩。
