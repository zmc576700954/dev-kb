# 多 seed 重验结论

> **后续更新（2026-11-03）**：本决策的三条前提已变化——(1) 训练数据从 122 条扩到 v5 的 302 条并重训 3 seed；(2) test2 已一次性消耗，不再是 sealed；(3) 默认模型已从 0.5B bf16 切到 Qwen3-4B-Instruct-2507 MLX 4-bit。v5 在 dev 120 上增益 +0.367～+0.408，但 test2 仅 1/3 seed 过判定线且 summary 退化，故“不采纳 LoRA 为默认”这一结论仍成立，理由已改为 held-out 不稳定，而非“样本量不足无法评估”。见 [test2 验收结论](../06-微调与训练/07-test2验收结论.md)、[test2 验收与 dev120 乐观偏差](../07-决策日志/09-test2验收与dev120乐观偏差.md)。

> 迁移说明（2026-11-04）：本篇从 `07-决策日志/06-多seed重验结论.md` 移入 `99-归档/`，状态标为已归档，正文数字与结论未改；当前结论见 [test2 验收结论](../06-微调与训练/07-test2验收结论.md)。

> 2026-11-03 决定：在 3 个训练 seed 的新口径重验后，仍暂缓采用 LoRA。dev40 三个 seed 全字段差值为 +0.10 / +0.05 / +0.075，方向一致但全部不显著且低于 MDE；dev2 为 −0.05 / 0 / 0，方向不一致。按预注册判据，结论是“无法判定，LoRA 在 122 条训练数据下不可评估”，不追加 epoch 或调参凑结果。

## 背景

week3 只训练了 1 个 adapter（seed 42），评测又是在 outlines 默认采样口径下做的，既没有训练侧复现，也没有可用的配对统计。week4 把评测固定为 greedy 并引入 McNemar、配对 bootstrap、Wilson 与 MDE。week5 在此口径上用同一份 train 122 / valid 20、同一套超参训练 seed 0/1/2 三个 adapter，再与基座在 dev40 上配对比较，dev2 作为旧 test 附加参考。

## 备选方案

| 方案 | 证据 | 取舍 |
|---|---|---|
| 采用 LoRA 为默认 | dev40 差值 +0.10 / +0.05 / +0.075，但 p=0.388 / 0.791 / 0.549，CI 全部跨 0，差值低于配对 MDE 0.21–0.24；dev2 为 −0.05 / 0 / 0 | 否 |
| 继续用基座加 outlines 加后处理 | 基座 dev40 0.450，与 LoRA 无统计差异；耗时 0.60 s 对 0.84–0.85 s | 采用 |
| 追加 2–3 epoch 或调参凑显著 | 本轮没有方向一致且显著的收益；继续调参等于用 dev 拟合结果，且样本量不足 | 否 |
| 扩样本后再判断 | 要可靠检出 0.075–0.10 的配对差异，按观测不一致率估算需要约 230–410 条配对样本 | 留到下一轮 |

## 决策

- 不采用任何 seed 的 adapter 为默认；默认仍是基座、v4 提示词、outlines、greedy、后处理。（**该默认已于 2026-11-03 模型切换，改为 Qwen3-4B-Instruct-2507 MLX 4-bit，见 [回归门禁与阈值](../08-应用层/03-回归门禁与阈值.md)**）
- 不追加 epoch、不调 lr / rank / dropout、不按 dev2 回调参数。
- 把本轮记为**负结果/不确定结果**：不是“LoRA 被证明无效”，而是“当前 40 条 dev、122 条训练数据不足以评估 0.05–0.10 量级的差异”。
- week8 把 dev 扩到 120、语料扩到 60，但**没有重训 LoRA**，所以本决策当时只覆盖 n=40（dev40）与 n=20（dev2）；week8 之后 v5 已重训并给出 dev 120 / test2 结果，见文首“后续更新”。
- test2 55 条在 week5 时保持 sealed，不用于本轮判断；该状态已于 2026-11-03 test2 验收时解除。

## 后果

- `data/processed/lora-seed0-adapter/`、`lora-seed1-adapter/`、`lora-seed2-adapter/` 保留，不合并、不接入默认评测。
- 评测报告必须同时给逐 seed 差值、p 值、CI 与 MDE，不能只报三个 seed 的均值。
- dev40 的 product / summary 上升与 order_id 下降可以记为“跨 seed 方向稳定”，但在样本量补足前不作为采用理由。
- 若下一轮继续微调，先扩 dev 或使用更多 valid，再决定是否值得训练更多 seed。

## 什么时候重新评估

- 配对样本量达到约 230 条以上（目标检出 0.10），或 410 条以上（目标检出 0.075）；
- 训练侧至少 3 个 seed 的 valid loss 都稳定下降，且不是只拟合 122 条训练样本；
- product 与 summary 的提升在扩样本后仍跨 seed 稳定，同时 customer_name、order_id 不回退；
- 候选配置写死后，test2 只跑一次，并给 Wilson 区间；不因结果回调参数。
