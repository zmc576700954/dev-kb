# 训练数据 v5 与工程化配置

> 本轮把微调从“1 epoch 冒烟”改成可配置实验：训练集 302 条、valid 40 条、dev120 与 test2 封存不参与训练；训练脚本支持超参、序列打包、早停、逐 step loss、hash 与内存记录。

## 1. 训练数据 v5

`evals/cases_v5.jsonl` 共 537 条 = 旧 297 条 + 新增 240 条。来源：`scripts/build_cases_v5.py`、`evals/data-mix-v5.json`。

| 项 | 数值 |
|---|---|
| train | 302（旧 82 + 新 220） |
| valid | 40（旧 20 + 新 20） |
| dev120（评测） | 120，未参与训练 |
| test2 | 55，继续封存，本轮未评测 |
| 新增样本 | 240（合成 200 + 从错例改写 40） |
| 新样本平均长度 | 47.6 字（合成 52.0 / 改写 25.6），dev120 为 48.9 字 |

### 一处必须修的旧问题

v4 的 `train` 122 条里有 **40 条与 dev120 重合**（旧 dev40 被拿去训练），因此旧的 dev40 结果其实是“训练集内评测”。v5 把这 40 条从 train 移除（`split_v5.json.removed_from_old_train`），再补新样本，使 train / valid / dev 三者严格不重合。来源：`evals/split_v5.json`、`scripts/check_leakage.py`。

### 失败模式配比

| 模式 | 新增条数 | 说明 |
|---|---|---|
| urgency 边界（中/低/高） | 50（26/8/16） | 无硬时限只到中；“今天/立刻/等不了”才是高 |
| 其他 vs 咨询 | 35（其他 20 / 咨询 15） | 办理动作→其他；只问规则→咨询 |
| 抽象服务名必须填 | 30 | 保险/会员/机票等也是 product，不能给 null |
| product=null | 15 | 原文无商品名词，禁止推断 |
| 部件不并入 | 25 | “滚筒/滤芯/风扇”是部件，product 仍是整机 |
| 姓名句式 | 20 | “X的/我是X/X来电”vs“朋友/先生”（null） |
| 订单号 | 15 | 原文有则复制；说“忘了/没有”则为 null |
| 多诉求 summary | 10 | 主诉求优先 |
| 从 dev120 错例改写 | 40 | 只保留产品/诉求/紧急度事实 |

来源标记：合成 200、从错例改写 40；旧 40 条真实工单仍保留 `source` 原值。改写样本**不写入姓名与订单号**——既避免与 dev120 泄漏，也不编造身份。

### 自动校验

生成时逐条断言：姓名/订单号/product 必须是原文子串或 null；订单号必须匹配 `[A-Z]{1,4}\d{8,}`；紧急度必须与文本中的硬时限/宽松信号一致；议题型必须有对应动作词；summary ≤30 字。240/240 通过。泄漏检查（`evals/leakage-check-v5.json`）：dev120 / test2 / valid 的精确重合 0、订单号重合 0、姓名重合 0、文本疑似泄漏 0。

已知局限：dev120 被用于失败模式定位与改写，因此 dev120 上同类模式的增益偏乐观；test2 未参与，保持封存。

## 2. 训练脚本能力

`scripts/train_lora_epoch.py`（本轮重写）：

| 能力 | 实现 |
|---|---|
| 超参 | `--r` / `--lora-alpha` / `--lora-dropout` / `--lr` / `--epochs` / `--warmup-ratio` / `--target-modules` / `--grad-accum` / `--max-len` |
| loss 记录 | 每个 micro/opt step 写 train loss；每个 epoch 写 valid loss；同一 token 级 CE 口径，token 加权 |
| 早停 | `--patience 2`，按 valid loss，保存最优 epoch 的 LoRA 权重 |
| 序列打包 | `--packing 1`：贪心拼到 `max_len`；4D block-diagonal mask 禁止跨样本注意力；prompt 与拼接边界 labels=-100 |
| 优化开关 | `--grad-checkpointing 1`；`--optimizer adamw8bit`（MPS 不可用则返回 exit=3 并给原因） |
| 可复现 | config hash、train/valid 文件 sha256、seed、adapter 文件 sha256 |
| 资源 | 逐 opt step 采样 MPS current allocated、driver allocated、进程 maxrss；步时与 tokens/s |

注意内存口径：脚本同时记录三种值。报告统一以 **MPS current allocated** 为主，driver allocated 仅作参考（该值在本机明显高于物理内存占用，不作为结论）。
