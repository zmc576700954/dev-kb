# 测试集与划分

> 记录评测集从 30 条扩到 217 条的划分方式、sealed 规则与泄漏检查结论，并区分“能判断修复效果”与“能当泛化估计”的数据。当前数据集为 v5（537 条），test2 已于 2026-11-03 一次性消耗。

## 数据集演进

- 第一周 `evals/cases.jsonl` 30 条，dev 20 / test 10。
- 第二周扩到 60 条，dev 40（old-30 全部降级）/ test 20。
- week2b 扩到 180 条 `evals/cases_v2.jsonl`：旧 60 条加新增 120 条（c061 至 c180）。
- week3 扩到 217 条 `evals/cases_v3.jsonl`：在 v2 基础上新增 25 条 sealed test2（c181 至 c205）和 12 条 train 投诉类（c206 至 c217）；v2 的 id 与标签均未改动。

来源：`evals/cases.jsonl`、`evals/cases_v2.jsonl`、`evals/cases_v3.jsonl`、`evals/expansion_c_summary.json`、`evals/week2b-report.md`。

## sealed 规则

- test2 55 条此前一直封存；2026-11-03 一次性运行 base vs LoRA seed 0/1/2 的 held-out 验收，之后标记 consumed，后续仅作回归。
- 评测前，test2 不参与提示词、后处理、阈值、LoRA 超参与早停的任何决策；本次验收使用已冻结的配置，不因结果回调参数。
- 本次验收的判定规则在运行前固定：p<0.05、bootstrap 95% CI 下界 >0、Δ 超过配对 MDE，三项全满足才算有效。结果仅 seed 1 过线，故不采纳 LoRA 为默认。来源：`evals/test2-report.md`、`kb/kaiwu/06-微调与训练/07-test2验收结论.md`。
- 旧 test 20 已在 2026-11-02 降级为 dev2，原因是错误样本已被逐条查看，且 n=20 的置信区间过宽。来源：`evals/test-milestone-1-report.md`、`evals/week2b-report.md`。

## 每类数据能回答什么

| 集合 | 可用于 | 不可用于 |
|---|---|---|
| dev2 20 | 缺陷修复前后的条数变化、回归是否退化 | 泛化估计：旧 test 已被逐条查看，week3 仍用它迭代 |
| 旧 dev 40 | 与历史结果对齐、同类缺陷的回归复核 | 泛化估计：曾用于提示词选型 |
| test2 55 | 已消耗：2026-11-03 一次性 held-out 验收 | 后续选型或泛化宣称：只能作回归集 |
| valid（v5） | 40 | 训练期 loss 与早停；不用于最终效果 |

这条边界是 week3 报告把“缺陷计数”和“准确率”分开写的原因：确定性缺陷计数由同一 run 的 raw 与 final 直接相减，能说明修复作用；准确率是在已看过或调过参的集合上测的，只能当回归信号。

## 泄漏检查

`scripts/check_leakage.py` 对 train 122 分别与 test2 55、dev2 20、valid 20 比较，结论 PASS：

| 对比 | 原文重合 | 订单号重合 | 姓名重合 | 文本疑似泄漏 | 模板相近待复核 | product 重合（信息性） |
|---|---|---|---|---|---|---|
| train vs test2 | 0 | 0 | 0 | 0 | 0 | 23 |
| train vs dev2 | 0 | 0 | 0 | 0 | 0 | 12 |
| train vs valid | 0 | 0 | 0 | 0 | 0 | 13 |

最高相似对仍是 c161 与 c121，2-gram Jaccard 0.485、SequenceMatcher 0.731，两条都是保修期咨询模板但产品不同。train 内部有两组同名不同单（何静 c013/c048，邓超 c020/c051），不与任何测试集重合。阈值是 Jaccard 大于等于 0.85 判泄漏，0.60 至 0.85 判模板相近待复核。完整明细在 `evals/leakage-check-v3.json`。

## 已知局限

- 泄漏检查是字面与 n-gram 层面，不能识别语义改写；
- 数据由单人按指南构造与标注，没有第二标注者与 Kappa；
- test2 从 30 扩到 55 后区间变窄，但没有计算具体置信区间，仍不足以区分很小的差异；
- dev2 与旧 dev 40 都已被使用过，本库不再把它们的结果当泛化估计。
