# 微调配置与冒烟结果

> 记录 LoRA 训练数据格式、序列长度、真实首轮配置与 1 epoch 训练的时间/内存数字；效果对比见 LoRA 首轮评测结果。

## 训练数据格式

复用 v4 的 chat 结构：system 放抽取规则，user 与 assistant 放 3 组 few-shot，最后一条 user 是待抽取原文，assistant 目标是 6 字段 JSON。训练脚本用 `apply_chat_template(add_generation_prompt=True)`，把 prompt 部分 label 置 -100，只对 assistant 目标计 loss。

`data/processed/lora_train.jsonl` 122 条，`data/processed/lora_valid.jsonl` 20 条。旧 dev 40 条的 summary 目标是人工补写；其余 82 条（v2 新增 70 加 v3 新增 12）由关键词组确定性合成，偏短、偏模板化，这是本阶段的已知折衷。来源：`evals/week2b-report.md`、`scripts/build_dataset_b.py`、`scripts/expand_dataset_c.py`。
