# 扩样本后的对比结论

> **后续变更（2026-11-03，同日）**：本文的检索结论（RRF 保持 observe、语料 60、baseline 重写）继续有效；但“保持 bf16 + outlines 为默认”已被**模型选型**推翻——默认改为 Qwen3-4B-Instruct-2507 MLX 4-bit（dev120 全字段 0.542 对 0.5B 的 0.292，p=3.6e−05、超 MDE）。此外 test2 已于同日消耗，“test2 未运行”只描述当时状态。见 [模型选型](../06-微调与训练/08-模型选型.md) 与 [test2 验收](../07-决策日志/09-test2验收与dev120乐观偏差.md)。

> 迁移说明（2026-11-04）：本篇从 `07-决策日志/07-扩样本后的对比结论.md` 移入 `99-归档/`，状态标为已归档，正文数字与结论未改；其中仍有效的检索口径见 [混合召回 RRF](../08-应用层/04-混合召回RRF.md)。

> 2026-11-03 决定：dev 40→120、语料 30→60 后，**不更换默认抽取方案，不把 RRF 升为阻塞项**。理由是：MLX 4-bit + 约束方案与 bf16 + outlines 的准确率差异仍不能判定（+2.5pp 全字段，p=0.690，MDE 0.113）；RRF 显著优于纯向量（p=2.1e−05），但相对纯 BM25 仍不能判定（+0.8pp，p=1.000，MDE 0.093）。语料扩容解决了 recall@3 饱和，这一点可以定论。

## 背景

week7 在 dev40 / 30 条语料上做过同口径对比，结论大多是“不能判定”：抽取两组 p=1.000，检索 BM25→RRF p=1.000、向量→RRF p=0.125。week8 按建议把 dev 扩到 120（新增 80 条合成样本）、语料扩到 60（新增 30 条相邻政策），用同一 prompt、同一后处理、同一 seed 重跑，并给每组配 McNemar、bootstrap CI 与 MDE。

## 备选方案

| 方案 | 证据 | 取舍 |
|---|---|---|
| 保持 bf16 + outlines 为默认 | 全字段 0.267、JSON 1.000、0.58 s/条；与 MLX 差 +2.5pp 但 p=0.690 | 当时采用；**2026-11-03 已被模型选型推翻** |
| 改用 MLX 4-bit + 约束为默认 | 全字段 0.292、JSON 1.000、0.28 s/条，磁盘 276 MB；准确率优势低于 MDE | 否（工程收益保留为可选） |
| 把 RRF 升为阻塞门禁 | 相对纯向量显著（p=2.1e−05）；相对纯 BM25 不显著（+0.8pp，p=1.000） | 否，保持 observe |
| 把 dev 120 当泛化估计 | 旧 40 条已并入 train，只有新增 80 条隔离；test2 当时未运行 | 否 |
| 继续扩样本以判定 2.5pp | 按当前不一致率粗估需约 2,600 条配对样本 | 留到下一轮 |

## 决策

- 默认抽取口径当时不变：基座 + v4 prompt + outlines + greedy + 后处理。（**2026-11-03 已被推翻**：默认改为 4B MLX 4-bit。）
- MLX 4-bit + 约束方案保留为“工程可选路径”：JSON 1.000、延迟约减半、磁盘约 1/3.5，但不作为默认，也不宣称更准。（**2026-11-03 后续**：4B 的 MLX 路径已成为默认；0.5B 的这一对比仍只说明该模型的量化代价不可判定。）
- RRF 在回归配置中保持 `observe`：记录 recall@1 / MRR / 主 gold 漂移，不改变退出码；纯 BM25 的阻塞级别不变。
- 回归基线按新样本量重写：`sample_size=120`、`corpus_size=60`，`change_date=2026-11-03`。
- test2 55 条在本轮（week8）继续 sealed，不因本轮结果回调参数；**2026-11-03 已一次性消耗**，此后仅作回归。

## 后果

- 任何引用“准确率 0.45 / 0.475”的旧表述都作废；在 2026-11-03 时点，dev120 下是 0.267（0.5B bf16）/ 0.292（0.5B MLX）/ 0.542（4B MLX，单遍生成），且都不能当泛化估计。**当前 v9 已到 0.833 / 0.867（2026-11-05，两遍生成）**，本页其余数字均为历史。
- 检索报告必须同时写“相对 BM25 不显著”和“相对向量显著”，不能只写“RRF 更好”。
- `evals/regression_config.json` 的阈值仍按新基线有效；观察项回退不影响退出码，阻塞项回退退出 2。
- 新增 80 条样本、120 条 gold 与 30 条语料均为单人合成标注，不用于对外泛化声明。

## 什么时候重新评估

- 配对样本达到约 2,600 条，或改用方差更小的重复测量设计，再判断 MLX 与 bf16 的 2.5pp 差异；
- 真实语料接入后，在 `app/kb_corpus_real/` 上重跑检索三方对比，语料规模与同主题密度都远大于当前 60 条；
- 若要把 RRF 升为阻塞项，先在 ≥120 条独立样本上得到 BM25→RRF 的显著且超过 MDE 的增益，再改门禁级别；
- 出现第二标注者与 Kappa 后，重标 120 条 gold，先看标签一致性再谈模型差异。
