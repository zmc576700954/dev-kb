## 刻意未安装

| 包 | 原因 |
|---|---|
| bitsandbytes | 面向 CUDA 的 8-bit 优化器与量化实现，macOS arm64 无可用 CUDA 后端 |
| flash-attn | 需要 CUDA 与编译期 kernel，macOS 无对应实现 |
| vLLM | 官方推理引擎面向 Linux 与 NVIDIA、AMD、TPU，本机为 arm64 macOS |
| DeepSpeed | 依赖 CUDA 与 NCCL 的分布式训练栈，单机 macOS 无意义 |

因此标准 QLoRA 路线不可直接复用；本机可行路线是 MLX 量化，或 torch 侧 bf16 LoRA。

## 冒烟实测

设备 mps，dtype bfloat16，greedy 解码，单次运行，未取多次平均：

| 指标 | 实测值 |
|---|---|
| 模型加载耗时 | 1.33 s / 1.37 s |
| 加载后 RSS | 881.4 MB / 881.8 MB |
| MPS 已分配显存（加载后） | 960.1 MB |
| MPS driver 占用（加载后） | 1040.5 MB |
| 首 token 时延 | 130.7 ms / 137.7 ms |
| 生成 60 新 token 总耗时 | 0.45 s / 0.46 s |
| 结构化抽取耗时 | 0.48 s |
| 进程峰值 RSS | 1,077,313,536 bytes，约 1027.4 MiB |

`torch.mps` 没有 peak 统计 API，表中 MPS 观测峰值是三个采样点的最大值，不是严格意义的瞬时峰值。来源：`docs/env.md`。
