# kaiwu 知识库

> kaiwu 项目知识库的唯一入口，汇总环境实测、评测口径、提示词与约束解码、数据标注、微调现状与关键决策。

## 这个库的用途

记录 kaiwu 工作区里已经验证过的事实，以及为什么这样选。代码与实验产物仍在 `scripts/`、`evals/`、`data/`；本库只做索引与结论沉淀，数字均标注来源文件。

结构遵循通用知识库规范：每篇文档首行是四键 frontmatter，H1 下有一句摘要，末尾有相关文档；所有站内链接以 `./` 或 `../` 开头。校验命令是 `python scripts/check_kb.py --project kaiwu --strict`。
